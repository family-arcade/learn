The starter carries its rules for AI helpers in two files with the same
content:

- `CLAUDE.md`, which Claude Code reads automatically;
- `AGENTS.md`, which Codex and other assistants read.

They explain the game's layout, [the kit](/reference/kit/), the
[rules every game keeps](/reference/rules/), how to test and build, and how
to try play together on one computer.

If you use an assistant that reads neither file, start every session with:

> Read AGENTS.md in this repository and follow it for everything you change.

## If you change the rules

The files are yours. If your family wants a different rule (say, a game for
one device only, without play together), edit them and tell the assistant.
Keep rules 1 to 3 of [Rules every game keeps](/reference/rules/): they are
what makes a game safe to share with other families' children.
