Every game made from the starter keeps these rules. Claude knows them from
the starter's `CLAUDE.md`; this page is for the grown-ups.

1. **Nothing from other websites.** No ads, no trackers, no analytics, and no
   pictures, sounds, fonts or code loaded from somewhere else. Everything the
   game needs is inside it. The only connection out is playing together.
2. **No links out and no pop-ups.** A game never sends a child to another
   website. "← Arcade" goes back to the arcade.
3. **No chat.** Players share their player name and nothing else they type.
   Messages between devices carry the game, nothing more.
4. **Playable by touch and by keyboard.** Every button is big enough to tap,
   and every action has a key too.
5. **Calm when asked.** If a device is set to reduce motion, there is no
   shaking, flashing or spinning.
6. **Readable.** Text is at least 16 pixels, with strong contrast.
7. **Kind with data.** A game saves only what it needs, only in the browser,
   only through the kit.
8. **Tested before it is published.** Every change runs the tests and the
   build; if either fails, nothing goes live.

:::caution[What is enforced, and what is not]
Rule 8 is enforced: GitHub will not publish a game whose tests fail. The
other rules are what Claude is told and what the starter does. Nobody checks
another family's game, which is why the arcade says: only add games from
people you know.
:::
