The starter template keeps its rules for AI helpers in one file, `AGENTS.md`:

- **Codex** and other assistants read `AGENTS.md` directly.
- **Claude Code** reads `CLAUDE.md`. That file points to `AGENTS.md` with
  the line `@AGENTS.md`, so Claude follows the same rules.

Nothing needs installing. The rules explain the game's layout, [the kit](/reference/kit/), and the [rules every game follows](/reference/rules/). They also tell the assistant:

- to ask the child 3 to 5 short questions, one at a time, before the first game, and to keep the first version basic;
- to offer two or three ideas after each version;
- to check every change before it says it is done: the tests, the build, and a search for anything loaded from other websites;
- how to try play together on one computer.

If your assistant reads neither file, start every session with this request:

<Prompt>Read AGENTS.md in this repository and follow it for everything you change.</Prompt>

## Talking in a terminal

In Claude Code in a terminal, type `/voice`, then hold Space while you speak. It works on macOS, Linux and Windows, with a microphone on that computer.

## Changing the rules

The file is yours. To change a rule, edit `AGENTS.md` and tell the assistant. For example, you might want a game for one device only, without play together. Keep rules 1 to 3 of [Rules every game follows](/reference/rules/). They make a game safe to share with other families' children.
