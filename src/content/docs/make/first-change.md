The child says what to change; the grown-up types it. Start with something
you will see straight away:

> Make the stars pink and the players twice as big. Then run the tests.

Claude reads the game, makes the change on a copy (a **branch**), runs the
tests, and tells you what it did.

## Put the change into your game

1. When Claude says it is done, click **Create PR**. A *pull request* is a
   request to put the change into your game.
2. GitHub opens. Click **Merge pull request**, then **Confirm merge**.
3. Wait a minute or two (the **Actions** tab shows a green dot when it is
   published), then reload your game's page.

Pink stars, big players. That is the whole loop:

**Ask → merge → play.**

Everything you do from now on is this loop again.

:::tip[Not quite right?]
Say so before you merge: "The pink is too pale, make it brighter." Claude
changes it on the same branch, and you merge once it is right.
:::
